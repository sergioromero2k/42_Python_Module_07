# DataDeck Execution Commands

Run these commands from the project's **root folder**:

### Exercises in order:

* **Exercise 00 (Base Card):**
  `python3 -m ex0.main`

* **Exercise 01 (Spell Cards):**
  `python3 -m ex1.main`

* **Exercise 02 (Elite Cards):**
  `python3 -m ex2.main`

* **Exercise 03 (Game Engine):**
  `python3 -m ex3.main`

* **Exercise 04 (Advanced Features):**
  `python3 -m ex4.main`

---
**Note:** Make sure each folder has its `__init__.py` file so that Python recognizes the modules.
